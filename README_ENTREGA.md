# Sistema Novo Stilo

Painel web para gestão do Salão Novo Stilo, com agenda, clientes, profissionais, serviços, caixa/PDV, estoque, relatórios e configurações.

## Como rodar

```bash
npm install
npm run dev
```

## Como gerar a versão de produção

```bash
npm run build
npm run preview
```

## Observação técnica

Esta entrega usa armazenamento local do navegador para manter a operação simples. Para uma versão SaaS com vários dispositivos, login e backup em nuvem, o próximo passo é conectar banco de dados e autenticação.
